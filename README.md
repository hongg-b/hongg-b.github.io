# Hong Je-Gal — Personal Homepage

Website: https://hongg-b.github.io/

A responsive academic homepage built with plain HTML and CSS. No installation or build step is required. Navigation, publication links, and BibTeX panels work without JavaScript.

## 내용 수정

- `index.html`: 소개, 링크, 소식, 논문 목록 및 디자인
- 프로필 사진은 `index.html`의 `<img class="portrait">`에 내장되어 있습니다. 사진을 새로 업로드한 뒤 해당 `src`를 파일 경로로 바꾸면 교체할 수 있습니다.
- GitHub에서 `index.html`을 열고 연필 아이콘을 눌러 수정한 다음 **Commit changes**로 저장합니다.
- `main` 브랜치의 루트 폴더를 GitHub Pages에 연결하면 변경 사항이 자동으로 배포됩니다.

이메일과 CV는 실제 주소 및 파일이 제공되면 추가할 수 있습니다. 공개할 정보만 올려 주세요.
